# TeeXaa® — تیکسا

نسخه اولیه و کامل رابط وب موبایل صرافی تیکسا با طراحی روشن، فارسی، مینیمال و انیمیشن ورودی.

## اجرا در GitHub Pages — بدون برنامه‌نویسی

1. یک Repository جدید در GitHub بساز.
2. فایل ZIP را از حالت فشرده خارج کن.
3. **تمام محتویات پوشه `TeeXaa`** را داخل Repository آپلود کن؛ یعنی `index.html` باید در ریشه Repository باشد.
4. در GitHub برو به:
   `Settings → Pages`
5. در بخش **Build and deployment**، گزینه Source را روی **Deploy from a branch** بگذار.
6. Branch را `main` و Folder را `/ (root)` انتخاب کن و Save بزن.
7. چند لحظه بعد لینک GitHub Pages ساخته می‌شود.

این پروژه استاتیک است و برای GitHub Pages ساخته شده؛ بنابراین Node.js یا نصب کتابخانه لازم ندارد.

## نکته مهم درباره نسخه فعلی

این نسخه یک **Frontend / Demo** کامل است. نرخ‌ها، سفارش‌ها و موجودی در این نسخه واقعی نیستند و اطلاعات تستی در LocalStorage مرورگر ذخیره می‌شوند.

برای تبدیل آن به صرافی واقعی باید در مرحله بعد به یک Backend امن، احراز هویت، KYC، دیتابیس، API قیمت، موتور سفارش، کیف پول، درگاه پرداخت، لاگ امنیتی و کنترل‌های قانونی/مالی متصل شود. این موارد عمداً بدون کلیدها و اطلاعات حساس داخل ZIP قرار داده نشده‌اند.

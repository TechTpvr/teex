# TeeXaa® v4.0.0

نسخه جدید TeeXaa با تمرکز روی هویت بصری اختصاصی صفحه ورود.

## تغییر اصلی
- لوگوی اصلی برنامه دست‌نخورده باقی مانده است.
- لوگوی ورود قبلی حذف شده است.
- لوگوتایپ اختصاصی TeeXaa برای Splash ساخته شده و با انیمیشن مرحله‌ای نمایش داده می‌شود.
- انیمیشن شامل شکل‌گیری لوگوتایپ، موج نور، هاله‌های Cyan/Blue/Purple/Pink و خط بارگذاری است.
- فونت رابط کاربری فارسی Estedad است و از فونت پیش‌فرض Samsung/Xiaomi استفاده نمی‌شود.

فایل‌ها در ریشه پروژه قرار دارند و پوشه assets یا icons وجود ندارد.
